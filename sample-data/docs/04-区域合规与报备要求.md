# AnyCompany 智能电表 区域合规与报备要求

> 本文档为演示用合成数据。区域划分与报备流程均为编造，不对应任何真实法规。

智能电表属计量器具，现场作业的报备要求按区域不同。**整表更换**与
**仅固件升级**的报备义务差别很大，作业前必须先判定属于哪一类。

## 1. 作业类型判定

| 作业类型 | 是否更换计量器具 | 是否影响计量特性 |
|---|---|---|
| 整表更换 | 是 | 是 |
| 更换通信模块 / 液晶屏 | 否 | 否 |
| 固件升级（OTA 或本地） | 否 | 否，除非涉及计量算法变更 |
| 更换后备电池 | 否 | 否 |

## 2. 华东区域（沪苏浙皖）

- **整表更换**：作业前 5 个工作日向属地计量技术研究院提交《计量器具更换报备表》，
  作业后 10 个工作日内上传换表前后的示值抄录与旧表封存照片。
  报备与作业记录**留存 3 年**。
- **固件升级**：不需要事前报备。若升级涉及计量算法变更，需在季度合规报告中汇总说明。
  4.x 分支中 4.2.1 属判据修复，**不涉及计量算法变更**。
- 旧表封存：换下的表体需保留 60 天方可返厂或报废。

## 3. 华南区域（粤桂琼）

- **整表更换**：无事前报备要求，作业后 15 个工作日内在省级平台补录即可。
  作业记录留存 2 年。
- **固件升级**：不需要报备。
- 旧表封存：30 天。

## 4. 西北区域（陕甘宁青新）

- **整表更换**：需事前报备，无固定提前天数要求，但须取得属地受理编号后方可作业。
- **固件升级**：单次批量超过 5000 台需事前书面告知属地主管部门。
- 旧表封存：60 天。
- 因冬季气温普遍低于 -10 ℃，西北区域现场作业窗口通常限定在 4 月至 10 月。

## 5. 报备材料清单（通用）

1. 《计量器具更换报备表》
2. 换表前后示值抄录单（双方签字）
3. 旧表铭牌与铅封照片
4. 新表检定证书编号
5. 作业人员计量作业证件号

## 6. 常见误区

- **把固件升级按整表更换报备**，导致流程时长从 0 天变成 5 个工作日，是最常见的
  无谓成本。判定依据只看是否更换计量器具。
- 华东区域留存 3 年、华南 2 年，两地记录留存年限不同，跨区域团队容易搞混。
