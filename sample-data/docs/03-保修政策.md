# AnyCompany 智能电表 保修政策

> 本文档为演示用合成数据。政策条款均为编造，不构成任何真实承诺。

## 1. 保修期起算

保修期自**出厂日期**起算，不以安装或投运日期起算。出厂日期见表体铭牌
`MFG` 字段，格式 `YYYY-MM`。铭牌模糊时以设备序列号第 3-6 位（年月）为准。

## 2. 部件分类与保修年限

保修年限按部件类别区分，**不按整表统一年限**。

### 核心部件：保修 5 年

- 计量芯片（MC-11 / MC-21 / MC-31）
- 电流互感器与分流器
- 主控 MCU
- 计量基准电压源

### 非核心部件：保修 2 年

- 通信模块（NB-IoT / 4G Cat.1 模组）
- 液晶显示屏
- 外壳与端子盖
- RS485 接口电路

### 易损件：不在保修范围

- 后备电池（建议每 4 年更换，对应错误码 E301）
- 密封圈、铅封线
- 表箱锁具

## 3. 固件缺陷的处理

**固件缺陷不受上述部件保修年限限制。** 只要该型号仍在固件维护期内，
因固件判据、统计逻辑等缺陷导致的误告警一律免费提供固件升级，
不占用部件保修额度，也不要求设备仍在部件保修期内。

固件维护期见《产品型号与固件版本说明》：EM-100 至 2028-12，EM-300 与 EM-500
自上市起 8 年。

## 4. 除外责任

以下情形不予保修：

1. 超出铭牌标称工作温度范围（-25 ℃ ~ +70 ℃）持续运行造成的损坏
2. 雷击、水浸、外力破坏、私自拆解或破坏铅封
3. 非 AnyCompany 授权人员刷写的非官方固件
4. 因用户侧接线错误（含相序错误）导致的计量偏差

## 5. 保修实施方式

| 部件类别 | 保修期内 | 保修期外 |
|---|---|---|
| 核心部件 | 免费整表更换 | 按备件价 + 上门费 |
| 非核心部件 | 免费更换该部件 | 按备件价 |
| 固件缺陷 | 免费升级（不限部件保修期） | 同左，以固件维护期为界 |

整表更换时，新表出厂日期重新起算保修期；仅更换非核心部件时，
**原核心部件保修期不重置**。
